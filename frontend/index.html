What is ChronoFlux?

AI network attack forecasting

Classical IDS only asks “is this malicious now?” ChronoFlux also asks “what attack stage comes next?” using an LSTM world model over chronological traffic windows.

01 DetectHybrid engineML + Isolation Forest + signatures → current stage & risk
02 ForecastWorld modelT1–T4 history → predict T5 / T6 / T7 before compromise
03 ObserveConsoleTraffic, devices, alerts — metadata only (no payload)
04 VerifyEvidenceElevated events → SHA-256 tamper-evident chain
